# Operations

Operator-facing runbooks for the running stack — how to drive load, enable
dev-only features, monitor cost, and tune background loops.

Distinct from [`../architecture/`](../architecture/) (how the system is
shaped) and [`../tech/`](../tech/) (which technologies it uses): these
documents are about **operating** the stack day-to-day once it's up.
